# Управление / Controls

Привязки рассчитаны на штатное управление игры. Изменённые игровые бинды могут менять результат. / Default game key bindings are assumed.

| Контроллер / Controller | Действие / Action |
|---|---|
| Левый стик / Left stick | Ходьба относительно взгляда / Head-relative movement |
| Правый стик влево-вправо / Right stick horizontal | Плавный поворот / Smooth turn |
| Левый / правый триггер | Стрельба соответствующей рукой / Left / right fire |
| Левый / правый хват | Подбор оружия (Q/E) / Weapon pickup |
| A | Прыжок / Jump |
| B | Рукопашный удар / Melee |
| X | Перезарядка / Reload |
| Y | Фокус / переключение цели (MouseWheelUp) / Target focus |
| Нажатие левого стика | Бросить оружие (MiddleMouse) / Drop weapon |
| Правый стик вверх / вниз | Выбор оружия/способности (3 / MouseWheelDown) / Weapon or ability selection |
| Нажатие правого стика | Меню / Pause menu |
| F8 (клавиатура) | Центрирование / Recenter |
| F9 (клавиатура) | Отслеживание камеры; не полный выход из VR / Toggle camera tracking |

В меню: стик — навигация, A/X — подтвердить, B/Y — назад.

Жест удара работает только при зажатом триггере соответствующей руки. Триггер также стреляет, если в руке оружие.

Граната: зажать хват возле бедра, вынести руку вперёд бросковым движением и отпустить хват. Нужна доступная граната в игре. Это вызов штатного броска G: отдельной модели гранаты в кисти и физической траектории по движению контроллера нет.
