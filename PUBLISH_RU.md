# Публикация на GitHub

1. Создайте пустой репозиторий AdventRisingVR в своём GitHub.
2. Загрузите **содержимое** этой папки в корень репозитория: README, src, tests, dist, licenses, скрипты и остальные подготовленные файлы. Не загружайте папку игры или рабочую папку со старыми логами. Папка dist намеренно включена и содержит четыре готовых файла мода.
3. Создайте Release с тегом **v0.8.30-dev**, названием **Advent Rising VR 0.8.30 — Pre-release** и отметкой предварительного выпуска.
4. В описание вставьте RELEASE_NOTES.md. Приложите готовые **AdventRisingVR-0.8.30-dev-Windows.zip** и **SHA256SUMS.txt** из соседней папки releases.
5. Игрокам давайте ссылку на Release и Windows.zip. GitHub автоматически создаёт Source code.zip — его не нужно выдавать за пользовательский установочный пакет.

Для следующих сборок: обновите версию, соберите Build.ps1 и выполните Package.ps1. Сверяйте VERSION, сообщения DllMain/Manage-Mod и документацию.

Файлы подготовлены локально. Репозиторий и Release автоматически не создавались. Лицензия проекта — MIT (LICENSE); лицензии включённых библиотек сохранены.
