# Advent Rising VR — 0.8.30-dev

Предварительная версия VR-мода для 32-битной Steam-версии Advent Rising. Основная связка: Quest 3S → Steam Link → SteamVR/OpenXR. Последнее исправление урона при фокусе в тире ещё требует проверки в игре; полное прохождение и другие шлемы не проверены.

## Установка

1. Скачайте **AdventRisingVR-0.8.30-dev-Windows.zip** из Releases и распакуйте целиком в отдельную папку. Не запускайте файлы прямо внутри ZIP.
2. Запустите оригинальную игру хотя бы один раз, затем закройте игру и VR-мост. Нужны Windows 10/11 x64, DirectX June 2010 (x86 d3dx9_43.dll) и Visual C++ 2015–2022 Redistributable **x86 и x64**. Установщики зависимостей берите у Microsoft.
3. Подключите шлем через Steam Link, запустите SteamVR и выберите SteamVR активной средой OpenXR.
4. Откройте **Check.cmd**, затем **Install.cmd**. Папка игры ищется в библиотеках Steam автоматически; при необходимости введите путь к Advent Rising или её System. При отказе в доступе нажмите правой кнопкой по Install.cmd → «Запуск от имени администратора».
5. Запустите игру обычным способом и загрузите уровень. Мост запускается автоматически. **F8** — центрирование.

Установщик проверяет совместимость Engine.dll, Core.dll и EonEngine.dll по SHA-256. При несовпадении установка прекращается. Версии игры и русификаторы, заменяющие эти DLL, не поддерживаются.

Скрипт сохраняет резервные копии, устанавливает четыре файла и настраивает default.ini/Mydefault.ini: 2560×1440 в окне, VSync выключен, чувствительность 0.28. Сохранения не меняются.

## Удаление и обновление

Закройте игру и мост, запустите **Uninstall.cmd** из старого пакета. После удаления можно ставить новый пакет. Храните папку System/AdventRisingVR-backup-* и AdventRisingVR-install.json: они нужны для восстановления.

Если файлы изменились после установки, удаление остановится и назовёт файл. Сохраните его копию; для файлов мода можно вернуть соответствующий файл из прежнего пакета и повторить удаление. Изменённые игровые INI сравните с резервной копией и восстановите вручную, сохранив нужные настройки. Не удаляйте резервную копию и манифест до окончания восстановления.

[Управление](CONTROLS.md) · [Решение проблем](TROUBLESHOOTING.md) · [Что изменено](RELEASE_NOTES.md).

Производительность зависит от ПК: мод рисует сцену дважды и читает кадры через CPU. При низком FPS уменьшите Render/GameWidth и GameHeight в System/AdventRisingVR.ini. HUD можно отключить через HUD/Enable=0. При дискомфорте прекратите проверку в шлеме.

Неофициальный мод; игра приобретается отдельно. Оригинальные DLL, ресурсы и скрипты игры в пакет не входят.
